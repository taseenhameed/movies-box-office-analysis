# 🎬 Movies Sales & Performance Analysis

An end-to-end data analysis project exploring 800 movies (2000–2024) to uncover patterns in box office revenue, ratings, budgets, and director/genre performance — built with **SQL Server** and visualized in **Power BI**.

## 📊 Project Overview

This project analyzes a movie industry dataset to answer real business questions a studio executive or analyst might ask: Which movies and directors perform best? Does budget guarantee quality? What genres carry the most financial risk? The workflow moves from raw data → SQL analysis → an interactive Power BI dashboard.



## 💡 Key Takeaways

- Box office success is heavily outlier-driven — a small number of breakout hits skew revenue figures far more than budget or rating do.
- Critical rating and financial performance are largely independent — high budgets and high ratings don't reliably go together.
- Director-level analysis reveals a meaningful split between "critically consistent" and "commercially dominant" directors.
